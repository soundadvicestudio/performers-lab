Export & Deploy
Download your site file and push it live to performers-lab.com.
How this works: Save your changes, then download index.html below. Drop it into your /performers-lab/public/ folder and push to GitHub. Vercel auto-deploys within 60 seconds.
Download Site File⌄

Downloads your complete site as a single HTML file with all edits baked in. Save as index.html and place in your public/ folder.

Push to Live Site⌄
1

Download index.html above

2

Replace the file in your repo

3

Push to GitHub

In Terminal: cd ~/performers-lab then git add . && git commit -m "Update site" && git push

4

Vercel auto-deploys

performers-lab.com updates automatically within 60 seconds. No action needed.
